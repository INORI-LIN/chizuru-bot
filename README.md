# chizuru-bot（千鹤）

面向 QQ 群的**文本**聊天机器人：使用 [AstrBot](https://docs.astrbot.app/) 作为插件宿主，
通过 NapCat + OneBot v11 接入 QQ，由 DeepSeek 生成回复，以《租借女友》中的水原千鹤为
角色参考。**非官方**、仅被 @ 时回复、不主动接话。

> 人设的核心原则：水原千鹤是个好女孩。

## 技术组成

| 项 | 选择 |
|---|---|
| 宿主框架 | AstrBot `==4.28.1`（Star 插件，平台适配限定 `aiocqhttp`） |
| QQ 接入 | NapCat + OneBot v11 |
| 模型 | DeepSeek API，经 AstrBot 原生提供商调用，不新建网关 |
| 运行环境 | Python 3.12.9，依赖与运行**全程 uv**，禁止 pip/pip3/python -m pip（含隐式调用） |

## 开发与验证

```bash
# S0 离线核验 + 全部单元测试（当前 803 项 + 8 个核验脚本，可重复）
bash scripts/s0/run_all.sh
```

- 该脚本经 `.runtime/astrbot` 的受控环境运行（`uv run --no-sync --offline`），不安装任何依赖。
- `environment/uv.lock` 必须与 `.runtime/astrbot/uv.lock` 一致；插件源码中不得出现
  `requirements.txt`，也不得导入 pip。
- 测试中的 audit hook 会拦截网络、子进程与（`.runtime/` 之外的）SQLite 连接。
- 离线测试通过**不等于**验收通过：真实传输与环境部分必须由 S4 的在线验证承担。

## 功能与数据边界（首版）

- **触发**：只处理显式允许群里指向本机器人的真实 @ 文本；私聊、机器人自身消息、含 @全体、
  未允许群一律不处理。
- **群上下文**：普通群聊仅在内存短暂保留（每群 30 条、10 分钟取严），只在有效 @ 时使用必要部分；
  使用时以短标签 + 转义昵称 + 相对时间注入，整批材料随请求临时标记、不落永久历史。
- **互动历史**：@ 对话经 AstrBot 会话存储保存，插件在读写两侧执行每群 20 轮 / 24 小时上限，
  并在**每次启动时做一次过期裁剪**；控制命令与（S3 起）使用长期记忆的整轮不进入共享历史。
- **删除覆盖**：退出/关闭/清空都会清会话历史**与平台消息历史**；清理失败不虚报已删除，
  会置降级保持相关能力关闭，并在 `千鹤 状态` 里登记"清理失败：N 次"（该计数跨重启保留，见 docs/03 R23）。
- **长期记忆**：默认关闭；只从本人 @ 时亲口说的话提取低敏偏好，可查看、纠正、删除。
  授权的两步确认入口已落地（`记忆 开启` 展示说明 → `记忆 确认开启` 启用，5 分钟内同群同人有效）；
  说明文案、群内查看提示与全部回执见 docs/03 附录 C.2/C.3 与 `memory/consent.py`。
  自动抽取默认关闭，需维护者先配置预算金额。
- **固定提示**：架构 §8.3 的"仅对已有有效 @ 给简短提示"已接线——@ 后只有图片/语音/文件时回一条能力提示；
  失败、空回复、排队、超预算与暂不可用各回一次简短文案（逐字取自 docs/03 附录 C.5，不调用模型、不写互动历史）；
  未分类的故障保持静默。
- **故障停用（401/402）**：鉴权失败或余额不足**首次出现即置粘滞降级**——此后聊天与抽取都不再发起付费调用，
  只对有效 @ 回一次暂不可用提示，`千鹤 状态` 的降级行给出原因；**解除只有进程重启/插件重载**
  （内存标志，不持久化；维护者修复后请重载插件。见 docs/03 附录 K 与风险 R30）。
- **控制操作**：`帮助`、`上下文 退出/加入`、`上下文 清空`、`记忆 开启/确认开启/状态/查看/查看 确认/纠正/删除/关闭/删除全部`、
  `群上下文 开启/确认开启/关闭`、`千鹤 暂停/恢复/状态` 等，权限由事件身份与显式配置映射决定，
  不让模型参与授权判定。**已实现（离线部分）**：全部上述命令——`帮助` 逐字回复使用说明（docs/03 附录 C.6），
  `群上下文 开启` 与 `记忆 开启` 逐字回复已定稿的说明全文，确认失败会重发全文并重开 5 分钟窗口；
  `记忆 查看` 同为两步，先提示群内可见再列出。
  `上下文 退出/加入`、`群上下文 关闭`、`上下文 清空`、`千鹤 暂停/恢复` 执行但**静默无回执**。
- **凭据**：QQ 登录态、OneBot Token、API Key 等只走运行时受限配置，
  **不进入仓库、文档、模型上下文与普通日志**。

## 首版非目标

图片理解、语音识别/合成、视频或文件解析；主动接话与定时问候；私聊聊天；联网搜索与工具调用；
跨群/跨机器人共享记忆；向量数据库、独立模型网关、多实例高可用；大量导入原作内容。
